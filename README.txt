FOLGAS TIC — APP 2.0 (BETA DE TESTE)

Como testar:
1. Abra index.html no navegador (Chrome/Edge recomendado).
2. Acesso Master inicial: usuário master / senha 1234.
3. No menu Usuários, o Master pode criar novos acessos.
4. O Dashboard classifica os motoristas por dias desde a última folga:
   - até 10 dias: VERDE / NORMAL
   - 11 a 15 dias: AMARELO / ATENÇÃO
   - acima de 15 dias: VERMELHO / CRÍTICO
5. A Auditoria registra login, cadastro de motorista, criação de usuário, lançamento, exclusão e exportação.
6. Os dados desta versão de teste ficam no armazenamento local do navegador. Não é uma base compartilhada entre computadores.

IMPORTANTE PARA A APRESENTAÇÃO:
Esta versão é um protótipo funcional para validação de fluxo. Para colocar em produção com vários computadores simultaneamente, a próxima etapa deverá migrar os dados e autenticação para um banco de dados/servidor.
